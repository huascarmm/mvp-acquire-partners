# Logos de credibilidad (opcional)

Coloca aquí logos de aliados/medios/instituciones que SÍ tengas derecho a mostrar
(no inventes endosos ni certificaciones). Formato recomendado: WebP/PNG con fondo
transparente, alto ~120px.

Luego decláralos en `assets/site.js`:

    credibility: {
      logos: [
        { src: "assets/img/logos/aliado-1.webp", alt: "Aliado 1" },
        { src: "assets/img/logos/aliado-2.webp", alt: "Aliado 2" }
      ]
    }

Si dejas la lista vacía, la fila de logos simplemente no se muestra.
